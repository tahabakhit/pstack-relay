# Contribute to pstack-relay

Use Go 1.23 or later, Git, and ShellCheck. Go is only for repository tools and tests. The installed runtime uses POSIX sh, awk, and standard Unix tools. Read [the design](docs/design.md) and [the delegation contract](overlay/delegation.md) before changing delegation.

## Check a change

Run these checks from the repository root.

```zsh
go test -race ./...
go vet ./...
go run ./cmd/upstream sync --check
go run ./cmd/build-plugin --check
shellcheck -s sh overlay/bin/pstack-relay plugins/pstack/bin/pstack-relay overlay/hooks/session-start.sh
claude plugin validate plugins/pstack
git diff --check
```

`sync --check` validates the recorded revision format without network access. `build-plugin --check` verifies generated bytes, executable bits, and the file list without writing. The generated tree must be current before tests that exercise the installed layout.

Tests use fixtures, captured Go runtime expectations, and fake harness processes. They do not establish authenticated model access or live backend behavior. Record live commands, outcomes, and qualifications in [the acceptance record](docs/acceptance.md). Keep credentials and model calls out of ordinary CI.

## Change the plugin

Keep `upstream/` pristine. Put runtime behavior in `overlay/`, build behavior in `internal/plugin/`, and exact host adaptations in `internal/plugin/adaptations.json`. Generate the plugin, then inspect the diff.

```zsh
go run ./cmd/build-plugin
```

The generator checks upstream source hashes before applying retained adaptations. It bundles the pristine setup template separately so installed setup can read upstream's role defaults.

Follow [upstream maintenance](docs/upstream.md) when importing Cursor changes. Upstream helpers may require Bun, Node.js, Python, or other tools. Read each helper's dependencies before running its checks. Go tests do not run those suites.

## Check a local marketplace install

Use empty temporary harness directories. These commands install the local marketplace without changing your normal harness configuration.

```zsh
relay_codex_home=$(mktemp -d)
CODEX_HOME="$relay_codex_home" codex plugin marketplace add "$PWD"
CODEX_HOME="$relay_codex_home" codex plugin add pstack@pstack-relay
CODEX_HOME="$relay_codex_home" codex plugin list
relay_claude_config=$(mktemp -d)
CLAUDE_CONFIG_DIR="$relay_claude_config" claude plugin marketplace add "$PWD"
CLAUDE_CONFIG_DIR="$relay_claude_config" claude plugin install pstack@pstack-relay
CLAUDE_CONFIG_DIR="$relay_claude_config" claude plugin list
```

Run the installed copy's `bin/pstack-relay version`, `setup --dry-run`, and `resolve` from outside the checkout. Use an isolated sheet and HOME for a fresh setup check, so an existing sheet cannot mask missing runtime data.

The package script makes a development archive of the same marketplace tree and verifies the extracted runtime.

```zsh
bash scripts/package.sh /tmp/pstack-relay-packages
```

The archive has no Go executables or architecture-specific binaries. Users install through the harness marketplaces. Building an archive does not publish a release or prove every target OS.

## Prepare a contribution

Describe the problem, resulting behavior, checks run, and remaining limits. Preserve copyright and license notices. Scan the staged patch before committing.

```zsh
git diff --cached
gitleaks git --staged --no-banner
```

Do not commit detected secrets. Report an unavailable scanner. Publication and hosted workflow execution require their own evidence.
